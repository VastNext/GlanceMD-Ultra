# d1. 现有代码可移植性审计

## 本维度要回答的问题

1. 哪些内容会直接导致非 Windows 编译失败？
2. 哪些内容即使编译通过也会产生功能或体验缺陷？
3. 哪些模块可以直接复用？

## 搜索覆盖情况

完成两轮仓库审计：第一轮覆盖 `Cargo.toml`、`build.rs` 和全部 Rust 模块；第二轮按 Windows API、快捷键、窗口装饰、自定义协议、文件关联与图标等关键词核对前端及锁文件。关键位置均回到当前源码确认。继续搜索未发现其他操作系统专属调用，达到本维度停止条件。

## 关键发现

### 直接编译阻塞

- `Cargo.toml` 需要把 `webview2-com`、`windows` 移入 Windows target-specific dependencies；`winresource` 应变成 Windows target-specific build dependency。
- `build.rs` 必须根据 `CARGO_CFG_TARGET_OS` 只在 Windows 目标运行资源编译。仅用 `#[cfg(windows)]` 判断 build script 宿主会在交叉编译时判断错误。
- `main.rs` 的 Win32 imports、WebView2 extension traits、resize controller 代码以及检测 stdin 是否为管道的 Win32 FFI 都需拆成平台实现或 `cfg` 分支。
- `single_instance.rs` 整个模块是 Windows 专属。最小方案是先在 macOS/Linux 禁用单实例；完整方案应抽象成统一接口，在 Unix 使用锁文件/Unix domain socket，并保留“转发打开文件”能力。

### 编译后仍需适配

- 自绘、无边框、右侧 Windows 风格窗口控制在 macOS 不符合平台习惯；Linux 各窗口管理器的拖动区域、最大化和焦点行为也要实测。首版最稳妥的策略是 macOS 使用系统装饰，Windows 保持现状，Linux先用系统装饰或在 X11/Wayland 均验证后再启用自绘。
- macOS 应把快捷键主修饰键抽象为 `e.metaKey || e.ctrlKey`，UI 文案显示 `⌘`；Ctrl+滚轮缩放可保留，但触控板 pinch/系统缩放事件需要实测。
- 当前 `#![windows_subsystem = "windows"]` 应改为 `#![cfg_attr(target_os = "windows", windows_subsystem = "windows")]`。
- 字体回退已经包含 `-apple-system`，但编辑器首选字体仍偏 Windows；这是视觉优化项，不是阻塞项。
- `std::process::exit(0)` 关闭窗口会绕过常规析构；现有行为在 Windows 已存在，跨平台时更适合向事件循环发退出事件，但不属于最小编译阻塞。

### 可直接复用

- Markdown 解析、高亮、编辑器、多标签、主题、目录、查找等前端业务逻辑可复用。
- `file_ops.rs` 使用的 `rfd` 支持 Windows/macOS/Linux；当前同步调用位于主线程，符合 macOS 对原生对话框的建议。
- `window_state.rs` 使用 `dirs::config_dir()`，会自动落到各平台合适的配置目录。
- 内嵌资源、自定义协议 handler、IPC JSON 协议、文件读写和 PNG 窗口图标解码的核心逻辑可以保留，但 WebView 创建和初始 URL 要平台化。

## 分析

项目不是架构上被锁死在 Windows，而是“跨平台库之上叠加了若干无隔离的 Windows 专属实现”。最小重构边界可以很窄：把平台差异集中到 `platform/` 或少数 `cfg` 函数，前端及 IPC 业务层无需重写。最大的功能性决策是单实例：若首版允许每次打开都新建窗口，工作量明显下降；若要求三平台行为完全一致，就需要同时解决 Unix IPC、macOS Finder Opened 事件和 Wayland 聚焦限制。

## 对终稿的贡献

提供 Windows 专属代码清单、最小平台抽象边界，以及“编译必做”和“体验优化”的优先级划分。

## 不确定性与空白

- 当前环境没有 Rust/Cargo 命令，无法执行非 Windows target 的实际 `cargo check`；结论来自源码和锁文件审计。
- 尚未在 macOS/Linux 验证自绘标题栏拖动、原生快捷键事件和 WebView 尺寸行为。

## 需要后续维度承接的问题

- Linux 应采用 `build()` 还是 `build_gtk()`，以及 Wayland 支持边界。
- 自定义协议初始 URL 在不同平台的正确形式。
- 安装包如何声明文件关联并把打开事件交给应用。
