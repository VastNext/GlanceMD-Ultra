# GlanceMD 项目工作区产品决策（已确认）

- 确认日期：2026-08-29
- 决策范围：项目工作区、文件树、监听、文件操作、搜索、设置、快捷键和可靠性
- 决策原则：除下列明确调整外，采用 `product-decisions-questionnaire.md` 中的全部推荐方案。

## 一、明确调整项

### 1. 项目和窗口

- 一个窗口只允许打开一个项目。
- 打开另一个项目时询问：
  - 在新窗口打开；
  - 替换当前窗口项目。
- 记住用户上次选择可作为后续体验优化，但每次是否继续询问由设置项控制。

### 2. 项目树和 Outline 布局

- 项目树与 Outline 必须同时展示。
- 支持两种布局：
  - **默认：两个独立竖栏并排**（问卷 6-B）；
  - **可选：Outline 放右侧**（问卷 6-C）。
- 设置页提供布局切换。
- 两个侧栏均支持折叠和拖宽，宽度与折叠状态持久化。

### 3. 文件树多选

- 第一版即支持 Ctrl/Shift 多选。
- 多选后支持批量移动、复制、删除等适合批量执行的命令。
- 多选状态下“在系统文件管理器中显示 / Open in Explorer”禁用，因为跨平台文件管理器对多目标选中支持不一致。

### 4. 默认文件显示与编辑范围

- 默认显示并允许编辑常见文本文件：
  - `.md`、`.markdown`、`.txt`
  - `.json`、`.yaml`、`.yml`、`.toml`、`.ini`、`.csv`
- 设置页提供“只显示 Markdown”选项。
- 后续允许用户配置可见/可编辑扩展名。

### 5. 排除目录

- 默认排除：`.git`、`node_modules`、`target`、`.venv`、`dist`、`build`、`.cache`。
- 所有排除目录和 glob 均可在设置中配置。
- 分别提供：
  - `files.exclude`
  - `search.exclude`
  - `files.watcherExclude`

### 6. 编码

当前版本不支持 GBK 等非 UTF-8 编码：`src/file_ops.rs::read_file()` 使用 `fs::read_to_string()`，非法 UTF-8 会直接报错；`write_file()` 写出 UTF-8。

因此第一阶段确定为：

- 支持 UTF-8 与 UTF-8 BOM；
- 保留原 LF / CRLF；
- 非 UTF-8 文件明确提示暂不支持，不做静默错误解码；
- GBK、Shift-JIS 等编码检测、选择和转换后置。

## 二、其余已接受的推荐方案

### 工作区和恢复

- 项目外单个 Markdown：若已打开项目且文件在项目内则复用项目；否则作为独立文件打开。
- 恢复上次项目、tab、活动文件、光标/滚动位置和树展开状态；设置可关闭。
- 欢迎页和工具栏菜单都提供最近项目，支持固定和移除失效记录。

### 项目树体验

- “定位当前文件”会展开祖先目录、选中并滚动到当前文件。
- 切换 tab 只同步高亮，不自动滚动；由定位按钮主动滚动。
- 单击文件永久打开 tab，不引入预览 tab。
- 完整键盘操作：方向键、Enter、F2、Delete、Shift+Delete、菜单键。
- 默认隐藏隐藏文件，设置可开启。
- 显示文件符号链接；默认不递归目录符号链接；禁止文件操作越出项目根。
- 设计目标为 10,000 文件以内项目不卡住 UI。

### 文件操作

- 新建文件未写扩展名时自动补 `.md`。
- 重名时阻止并提示重新命名，不自动覆盖。
- 重命名/移动已打开文件时同步更新 tab、保存路径、最近记录、搜索结果和树高亮。
- 项目树内部删除：
  - Delete → 系统回收站/废纸篓；
  - Shift+Delete → 永久删除，必须二次确认。
- 删除已打开且有未保存内容的文件时先阻止并提示。
- 外部删除时保留 tab 内存内容，显示“磁盘文件已删除”，提供另存为/关闭。
- 文件操作撤销作为必须能力：重命名、移动、可恢复的回收站删除支持 Ctrl+Z；永久删除不可撤销。
- 拖放默认移动，按 Ctrl 拖动复制；跨磁盘移动需复制后删除并处理失败回滚。
- 右键菜单包含：新建文件/文件夹、打开、重命名、删除/永久删除、剪切/复制/粘贴、复制绝对/相对路径、在系统文件管理器中显示、在终端中打开、刷新。

### 文件监听和冲突

- 未修改 tab：外部变化后自动重新加载，尽量保留光标与滚动位置，状态栏短暂提示。
- 有未保存内容：停止自动覆盖，使用编辑区顶部非模态横幅，提供：
  - 重新加载；
  - 保留编辑版本；
  - 另存为。
- 选择“保留编辑版本”后，保存时再次确认是否覆盖已变化的磁盘版本。
- 外部删除保留内存；外部移动可唯一识别时自动更新路径，否则按删除+新增处理。
- 提供“暂停文件监听”命令，可后置到第二阶段。

### 搜索和快速打开

- 全文搜索 Markdown 和受支持文本文件。
- 包含：大小写敏感、全词、正则、包含/排除 glob、取消、增量结果。
- 第一阶段只做搜索，全项目替换后置。
- Ctrl+P 按文件名快速打开为必须功能。
- 搜索结果点击后打开/切换 tab，跳到行列并选中匹配；split 下编辑与预览同步定位。

### 设置、快捷键和命令

- 全局设置 + 项目设置；项目设置覆盖全局。
- 设置以独立 tab 展示，左侧分类、右侧设置项和搜索；高级用户可打开设置 JSON。
- 快捷键页面支持搜索、录制组合键、冲突检测、清除、恢复默认、导入/导出。
- 快捷键冲突阻止保存，必须解决。
- 增加 Ctrl+Shift+P 命令面板，所有命令均可搜索执行。
- Windows/Linux 显示 Ctrl/Alt，macOS 显示 Cmd/Option。

### 保存和可靠性

- 自动保存默认关闭；支持关闭/延时/失焦模式。
- 崩溃恢复为必须能力。
- 切换项目/退出时列出 dirty 文件，支持全部保存、逐个处理、全部放弃、取消。
- 使用原子保存（临时文件写入后替换）。
- 大于默认 5 MB 的文件进入大文件模式，禁用实时预览、Outline 和高耗时功能；阈值可配置。

### 平台和边界

- Linux “在文件管理器中显示”允许降级为打开父目录。
- 支持在新窗口打开项目，每窗口一个项目。
- 完整国际化后置；第一阶段保持英文 UI，不阻塞核心功能。
- 允许二进制适度增长到 2–5 MB，以换取可靠的监听、搜索、回收站和恢复能力；仍应显著小于 Electron 应用。

## 三、发布成功标准

- Windows、macOS、Linux 均可打开项目、监听文件、执行文件操作和搜索。
- 外部修改在 dirty/clean 两种状态下都不丢数据。
- Delete / Shift+Delete 与 Windows 文件管理器语义一致。
- 10,000 文件项目可操作，扫描、搜索、监听不阻塞 UI。
- 项目树与 Outline 的默认并排布局、Outline 右侧布局均可用；与 split 共存。
- 1024px 宽窗口仍可操作，面板具备最小宽度、折叠和拖动约束。
- 多选批量文件操作可用，多选时 reveal 命令禁用。
- 设置和快捷键冲突可检测，支持恢复默认。
- 崩溃后可恢复未保存内容。

## 四、范围与工期修正

根据已确认范围，这不是 6–9 日的目录树功能，而是完整 Workspace 子系统。

- 单人薄原型：3–4 周。
- 基本可用：6–8 周。
- 推荐正式发布质量：**10–14 周**（多选、双布局、文件操作撤销、崩溃恢复提高了工作量）。
- 接近成熟项目型 Markdown 编辑器：3–6 个月。

应采用分阶段交付，而不是把全部逻辑继续堆进 `app.js` 和 `ipc.rs`。
