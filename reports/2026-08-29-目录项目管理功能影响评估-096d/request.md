# 研究请求

- 日期：2026-08-29
- 项目：GlanceMD
- 用户需求：评估增加类似项目管理的功能对整个项目的影响与工作量。
- 目标能力：
  1. 选择并打开一个目录。
  2. 展示目录内 Markdown 文件，用户可随意打开并复用现有 tab。
  3. 对目录树中的文件右键，提供“在系统资源管理器中显示 / Open in Explorer”。
- 需要回答：架构影响范围、实现方案、跨平台风险、测试与发布影响、工作量估计、建议的最小可行范围。
- 当前上下文：项目由 Peekdown 长期独立演进而来；Rust 后端负责原生能力与文件 I/O，JS 前端拥有 tab 状态。

## 范围演进

后续访谈确认该需求已扩展为完整工作区产品：文件监听、项目树与 Outline 同屏、多选、完整文件操作、全文搜索、设置、快捷键、命令面板、崩溃恢复等均为必需能力。正式产品名确定为 **GlanceMD Ultra**，完整方案见 `GlanceMD-Ultra-product-architecture-proposal.md`。

## 执行假设

- “项目管理”暂指单根目录文件浏览，不包含全文检索、Git、文件新建/重命名/删除、拖放移动、工作区多根目录、项目配置文件等能力。
- 第一阶段仅展示 Markdown 文件（`.md`、`.markdown`，是否包含 `.txt` 需产品决定）。
- Windows 文案为“在文件资源管理器中显示”；macOS 对应 Finder；Linux 需降级为打开父目录。
