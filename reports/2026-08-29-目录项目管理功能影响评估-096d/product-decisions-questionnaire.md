# GlanceMD 项目工作区功能决策问卷

**目的：** 一次性确认项目工作区、文件管理、监听冲突、搜索、设置和快捷键的产品边界，避免实施过程中反复追问。

## 已确认，不再询问

- 文件监听与自动刷新是必需能力。
- 项目树与 Outline 必须同时展示。
- 必须支持新建、重命名、删除、拖放移动、全文搜索。
- 必须增加设置界面和快捷键设置页面。
- 原“打开文件”按钮改为“打开目录”。
- 项目树顶部提供“定位当前文件”。
- 有未保存内容且磁盘被外部修改时停止自动覆盖，提供“重新加载 / 保留编辑版本 / 另存为”。
- Delete 移入系统回收站/废纸篓；Shift+Delete 永久删除。

## 回答方式

如果没有特殊要求，可直接回复：

> 全部按推荐方案。

有例外时回复：

> 除第 3、12、24 项外，其余按推荐。3=B，12=……，24=A。

## 一、工作区和启动行为

### 1. 一个窗口允许打开几个项目？

- A. 一个窗口一个项目；打开另一目录时替换当前项目
- B. 一个窗口多根目录工作区
- **推荐：A**。结构简单；需要多个项目时可开多个窗口。

### 2. 打开另一个目录时默认如何处理？

- A. 当前窗口切换项目
- B. 新窗口打开
- C. 弹出选择“当前窗口 / 新窗口”
- **推荐：C**，并记住用户上次选择。

### 3. 从资源管理器双击单个 `.md`、文件关联或命令行传入文件时如何处理？

- A. 继续作为独立文件打开，不建立项目
- B. 自动把父目录作为项目打开
- C. 若已有项目且文件在项目内则复用；否则独立打开
- **推荐：C**，兼容当前轻量查看场景。

### 4. 启动时是否自动恢复？

- A. 恢复上次项目、打开 tab、活动 tab、滚动位置、树展开状态
- B. 只恢复最近项目，不自动打开
- C. 总是显示欢迎页
- **推荐：A**，设置中可关闭。

### 5. 最近项目入口放在哪里？

- A. 欢迎页 + 工具栏菜单
- B. 仅欢迎页
- C. 仅菜单
- **推荐：A**，支持固定项目和移除失效记录。

## 二、项目树与 Outline 布局

### 6. 两者如何同时展示？

- A. 左侧同一栏上下分区：项目树在上、Outline 在下，中间可上下拖动
- B. 两个独立竖栏并排
- C. Outline 放右侧
- **推荐：A**，小窗口下最实用，也最接近编辑器侧栏习惯。

### 7. 面板是否支持折叠和拖宽？

- A. 整个左栏可左右拖宽；项目树/Outline 可单独折叠；上下分隔比例持久化
- B. 固定宽度，只能整体显示/隐藏
- **推荐：A**。

### 8. “定位当前文件”的行为？

- A. 展开祖先目录、选中并滚动到当前文件
- B. 只高亮，不自动展开
- **推荐：A**。如果当前文件不属于项目，显示不可定位提示。

### 9. 切换 tab 时是否自动在项目树定位？

- A. 自动定位并滚动
- B. 只同步高亮，不滚动；用户点击定位按钮时才滚动
- **推荐：B**，避免切 tab 时文件树频繁跳动。

### 10. 文件打开交互？

- A. 单击永久打开 tab
- B. 单击预览 tab，双击固定 tab
- **推荐：A**，延续当前 GlanceMD 简单模型，不引入 VS Code 式预览 tab。

### 11. 文件树是否需要完整键盘操作？

- A. 需要：方向键、Enter、F2、Delete、Shift+Delete、菜单键
- B. 第一版只支持鼠标
- **推荐：A**，快捷键系统与可访问性都依赖它。

### 12. 文件树是否支持多选？

- A. 第一版单选；后续再做多选
- B. 第一版支持 Ctrl/Shift 多选并批量移动/删除
- **推荐：A**，多选会显著增加拖放、菜单和冲突复杂度。

## 三、可见文件、过滤和符号链接

### 13. 项目树显示哪些文件？

- A. 所有文件，Markdown 可打开，其他文件显示但不可编辑
- B. 只显示 Markdown
- C. Markdown + 常见纯文本/配置文件，并允许文本编辑
- **推荐：C**：默认支持 `.md/.markdown/.txt/.json/.yaml/.yml/.toml/.ini/.csv`，后续设置扩展。

### 14. 是否显示隐藏文件？

- A. 默认隐藏，设置可开启
- B. 默认显示
- **推荐：A**。

### 15. 默认排除目录？

- **推荐默认排除：** `.git`、`node_modules`、`target`、`.venv`、`dist`、`build`、`.cache`；设置中可编辑 `files.exclude/search.exclude/watcher.exclude` glob。
- 如有不同请列出。

### 16. 符号链接策略？

- A. 显示文件链接；默认不递归进入目录链接；禁止文件操作越出项目根
- B. 跟随全部链接
- C. 完全隐藏链接
- **推荐：A**，避免循环和路径逃逸。

### 17. 预期最大项目规模？

- A. 1,000 个文件以内
- B. 10,000 个文件以内
- C. 100,000 个以上
- **推荐设计目标：B**；C 需要持久化索引和更复杂的增量架构。

## 四、文件操作语义

### 18. 新建文件默认扩展名？

- A. 没写扩展名时自动补 `.md`
- B. 原样创建，无扩展名
- **推荐：A**。

### 19. 新建/重命名重名时？

- A. 阻止并提示重新命名
- B. 自动追加 `(1)`
- C. 询问覆盖
- **推荐：A**，文件管理器式可预期行为。

### 20. 重命名或移动已打开文件时？

- **推荐：** 自动更新 tab 路径、标题、保存目标、最近记录、搜索结果和项目树高亮；不关闭 tab。
- 是否接受？

### 21. 删除已打开文件时？

- A. 删除后关闭对应 tab；有未保存内容则先阻止并提示
- B. 删除后保留 tab 为 Untitled/Deleted 状态
- **推荐：A**；外部删除则保留内存内容并显示“磁盘文件已删除”。

### 22. Shift+Delete 永久删除是否二次确认？

- A. 每次确认，并明确显示文件/文件夹名和不可恢复提示
- B. 不确认，完全遵循快捷键
- **推荐：A**。

### 23. 文件操作是否支持撤销？

- A. 支持 Ctrl+Z 撤销重命名、移动、回收站删除（可恢复时）
- B. 第一版不支持文件操作撤销
- **推荐：A**，但可以作为第二阶段；永久删除不可撤销。

### 24. 拖放移动的交互？

- A. 默认移动；按 Ctrl 拖动复制
- B. 只允许移动，不支持复制
- C. 每次询问移动/复制
- **推荐：A**，与 Windows Explorer 一致；跨磁盘时复制后删除需明确失败回滚。

### 25. 是否需要以下右键菜单？

推荐第一版全部包含：

- 新建文件 / 新建文件夹
- 打开
- 重命名
- 删除 / 永久删除
- 剪切 / 复制 / 粘贴
- 复制绝对路径 / 复制相对路径
- 在系统文件管理器中显示
- 在终端中打开
- 刷新

请指出需要删除或补充的项。

## 五、文件监听、自动刷新和冲突

### 26. 未修改 tab 的外部变化？

- **推荐：** 自动无提示重新加载，尽量保留光标和滚动位置；状态栏短暂显示“已从磁盘更新”。
- 是否接受？

### 27. 已确认的冲突提示采用哪种形式？

- A. 编辑区顶部非模态横幅：重新加载 / 保留编辑版本 / 另存为
- B. 模态对话框
- **推荐：A**，不打断其他 tab 操作。

### 28. 选择“保留编辑版本”后，再保存时？

- A. 再次确认“磁盘版本已变化，是否覆盖”
- B. 直接覆盖
- **推荐：A**，避免误覆盖外部修改。

### 29. 外部删除/移动？

- **推荐：**
  - 外部删除：tab 保留内存内容并显示“磁盘文件已删除”，提供另存为/关闭。
  - 外部重命名或移动：若能唯一识别则自动更新路径；无法可靠识别则按删除+新增处理。
- 是否接受？

### 30. 是否需要暂停文件监听？

- A. 设置/命令提供“暂停监听”，适合批量外部操作
- B. 不需要
- **推荐：A**，但可后置。

## 六、全文搜索和快速打开

### 31. 全文搜索范围？

- A. Markdown 和已支持的文本文件
- B. 只搜索 Markdown
- C. 所有可解码文本文件
- **推荐：A**，与项目树可编辑类型一致。

### 32. 搜索功能首版包含哪些开关？

- **推荐全部包含：** 大小写敏感、全词匹配、正则表达式、包含/排除 glob、可取消搜索、增量显示结果。
- 是否接受？

### 33. 是否第一版就做“全项目替换”？

- A. 需要，含逐项确认和全部替换
- B. 先只做搜索，替换后置
- **推荐：B**。全局替换需要备份、冲突和撤销机制。

### 34. 是否需要“按文件名快速打开”（Ctrl+P）？

- A. 必须
- B. 后置
- **推荐：A**，项目工作区中高频程度通常高于全文搜索。

### 35. 搜索结果点击行为？

- **推荐：** 打开/切换 tab，跳到行列并选中匹配；split 打开时编辑区和预览区同步定位。
- 是否接受？

## 七、设置、快捷键和命令系统

### 36. 设置作用域？

- A. 全局设置 + 项目设置，项目覆盖全局
- B. 只做全局设置
- **推荐：A**，项目设置文件建议放 `.glancemd/settings.json`；可设置为不自动创建。

### 37. 设置界面形式？

- A. 独立设置 tab，左侧分类、右侧设置项和搜索
- B. 模态窗口
- C. JSON 文件编辑
- **推荐：A**，另提供“打开设置 JSON”给高级用户。

### 38. 快捷键设置页面？

- **推荐：** 列出命令、默认快捷键、用户快捷键；支持搜索、录制组合键、冲突检测、清除、恢复默认、导入/导出。
- 是否接受？

### 39. 快捷键冲突策略？

- A. 阻止保存并要求解决冲突
- B. 允许冲突，后设置者覆盖
- **推荐：A**。

### 40. 是否增加命令面板（Ctrl+Shift+P）？

- A. 必须，所有命令均可搜索执行
- B. 不需要
- **推荐：A**。有可配置快捷键后，命令面板是统一命令模型的重要入口。

### 41. 是否统一跨平台快捷键显示？

- **推荐：** Windows/Linux 显示 Ctrl/Alt，macOS 显示 Cmd/Option；同一命令使用平台默认映射。
- 是否接受？

## 八、保存、恢复、编码与可靠性

### 42. 自动保存？

- A. 默认关闭；支持关闭/延时/失焦三种模式
- B. 默认延时自动保存
- C. 不做自动保存
- **推荐：A**，避免与外部修改冲突策略互相惊扰。

### 43. 崩溃恢复？

- A. 必须：未保存内容写入恢复区，下次启动提示恢复
- B. 后置
- **推荐：A**，项目型编辑器需要基本数据保护。

### 44. 切换项目/退出时多个未保存 tab 的处理？

- **推荐：** 展示文件列表，支持“全部保存 / 逐个处理 / 全部放弃 / 取消”。
- 是否接受？

### 45. 编码和换行符？

- A. 首版 UTF-8/UTF-8 BOM，保留原 LF/CRLF；非 UTF-8 提示不支持
- B. 增加编码检测和选择（GBK 等）
- **推荐：A**，编码检测可后置，但必须保留原换行符。

### 46. 保存方式？

- A. 原子保存：临时文件写入后替换，降低断电/崩溃损坏风险
- B. 继续直接覆盖
- **推荐：A**。

### 47. 大文件策略？

- **推荐：** 超过可配置阈值（如 5 MB）提示“大文件模式”，禁用实时预览、Outline 和部分高耗时功能。
- 是否接受？阈值希望是多少？

## 九、平台和产品边界

### 48. Linux “在文件管理器中显示”无法保证选中文件时？

- A. 接受降级为打开父目录
- B. 必须针对常见文件管理器逐个适配选中
- **推荐：A**。

### 49. 是否需要多窗口？

- A. 支持“在新窗口打开项目”，每窗口一个项目
- B. 只允许一个应用窗口
- **推荐：A**，可复用现有单实例转发但需要增加窗口/实例策略。

### 50. UI 语言？

- A. 继续英文
- B. 改为简体中文
- C. 增加中英文切换
- **推荐：C**，但完整国际化可作为独立阶段；第一阶段可保持英文避免阻塞核心功能。

### 51. 是否继续维持“约 800 KB、无额外运行时依赖”的体积目标？

- A. 严格维持，依赖和功能受此约束
- B. 可适度增大（例如 2–5 MB）换取监听、搜索、回收站等可靠能力
- **推荐：B**。完整工作区功能很难继续维持 800 KB，但仍可保持远小于 Electron 编辑器。

### 52. 第一版正式发布的成功标准？

推荐必须满足：

- Windows/macOS/Linux 打开项目、监听、文件操作、搜索均可用。
- 外部修改不丢数据。
- 删除符合 Delete/Shift+Delete 语义。
- 10,000 文件项目可操作，不阻塞 UI。
- 项目树、Outline、split 在 1024px 宽窗口仍可用。
- 快捷键冲突可检测，设置可恢复默认。
- 崩溃恢复可找回未保存内容。

请确认或修改。
