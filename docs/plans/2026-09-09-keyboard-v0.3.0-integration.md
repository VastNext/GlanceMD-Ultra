## 独立审查确认并已修复的产品缺陷（v0.3.0 随附）

- `workspace.fs.delete` 忽略 `permanent` 且与前端 `paths` 数组不匹配（删除命令整体静默失效）；已修复并区分回收站/永久删除。
- `fs_move`/`fs_copy` 同类 `paths` 载荷断裂；批量载荷含非字符串项或非 bool `permanent` 时整批拒绝，不再部分执行。
- `fs_reveal`/`fs_terminal` 绕过项目根边界；已统一经 `ensure_within_root`，覆盖绝对路径、`..` 穿越与符号链接逃逸。
- `settings.set`/`save` 未走 `migrate_checked`：未来版本配置会被覆盖损坏；现改为版本过高时拒绝落盘。
- 快捷键设置：冲突仅提示不阻止保存、非法 when 表达式令全部按键失效、编辑单条绑定覆盖同命令其余绑定、passthrough/platform 被硬置覆盖；均已修复并补测试。
- 快捷键持久化双事实源：localStorage 与 Rust schema v2 并存；已统一为设置文档事实源 + localStorage 一次性迁移（防重入标记），切方案按方案隔离保存。

## 体积决策（已决，2026-09-09）

v0.2.0 正式 Windows exe 为 5,241,344 字节（已超十进制 5 MB，距 5 MiB 余 1,536 字节）。候选 `d2f9ea9` 四平台 Build 全绿，Windows 正式 MSVC 产物实测 **5,695,488 字节（5.695 MB / 5.432 MiB）**。维护者决策：**放宽预算为 2–8 MB**（AGENTS.md / ADR / 主实施计划 / orchestration 已同步），减重（gzip 预压缩 + `opt-level="z"`）登记为 backlog FEAT-004 留待偿还；`release.yml` publish 前新增 Windows 产物 ≤ 8,000,000 字节硬校验。`strip = "none"` 与零外部运行时约束不变。
