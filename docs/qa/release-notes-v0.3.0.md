# 🎉 GlanceMD Ultra v0.3.0 — 快捷键全面进化与 Vim 模态编辑

> 本版本聚焦键盘工作流：双键位方案、快捷键助手、Vim 与快速大纲，并修复多项影响数据安全的缺陷。
> 🔍 上个版本：[v0.2.0](https://github.com/VastNext/GlanceMD-Ultra/releases/tag/v0.2.0)

## ✨ 新功能

### ⌨️ 双键位方案（Ultra Eclipse / VS Code）

- 🧩 全新命令—上下文—绑定快捷键系统：所有公开命令均有默认键，支持 `chord` 组合键（如 `Ctrl+K Ctrl+S`）、生效上下文（WHEN）与平台限定。
- 🌗 首装默认 **Ultra Eclipse 方案**（`Ctrl+O` 大纲、`Ctrl+Shift+O` 切换大纲、`Ctrl+3` 命令面板、`Ctrl+H` 搜索、`Ctrl+Shift+R` 快速打开等），一键切换 **VS Code 方案**（`Ctrl+P`、`Ctrl+Shift+P`、`Ctrl+Tab` 等）。
- 🔄 顶栏按钮与欢迎页卡片的快捷键提示随方案**动态刷新**。

### 🧭 Key Assist 快捷键助手

- `Ctrl+Shift+L` 呼出可搜索的快捷键助手：`↑↓` 导航、`Enter` 执行、`F2` 编辑快捷键、`Delete` 清除绑定，55 项命令全量呈现。

### 🍿 Vim 模态编辑

- `Alt+Shift+E V` 开启：`NORMAL` / `INSERT` / `VISUAL` / `VISUAL LINE` / `REPLACE` / 命令行模式，状态栏常驻模式提示与方块光标 ⬛。
- 🧮 常用 motion / operator / 文本对象 / 寄存器 / 宏录制，以及 `:w` `:q` `:wq` `:e` `:bn` `:set wrap` 等 Ex 命令；保存失败或取消时保持在 Vim 模式，不假退出。

### 📑 快速大纲

- `Ctrl+O` 呼出居中浮层大纲：实时过滤标题、`↑↓` 导航、`Enter` 跳转。
- 🖥️ 编辑 / 预览 / 分屏三模式分别精准落点、平滑居中发光与双栏协同滚动。

### ⚙️ 快捷键设置页与命令面板

- 🛠️ 设置 → 快捷键：按分类浏览 55 项命令，组合键录制、修改、清除与恢复默认；冲突或 WHEN 表达式非法时**拒绝保存**并给出提示。
- 🎛️ `Ctrl+3` 命令面板覆盖全部命令（含崩溃恢复与恢复区操作）。

## 🔧 改进

- 📌 **快捷键统一持久化**：全局设置文档成为唯一事实源，按方案独立保存；旧版本本地存储首次启动自动迁移（失败保留旧数据，下次重试）。
- 🛡️ 项目设置中的快捷键段保持全局限定：打开工作区不会静默改变快捷键，并给出明确告警。
- 💡 编辑器新增 3px 自定义光标，`Ctrl+L` 支持软换行下的逻辑行精确对齐，`Ctrl+Shift+↑/↓` 标题间跳转。
- 💬 关闭未保存标签页改为居中确认弹窗（不再使用系统对话框），批量关闭按数量一次确认。
- 🎨 深浅双主题下所有新增浮层（命令面板、Key Assist、快速大纲、关闭确认）延续紫粉渐变设计语言并保证对比度。

## 🐛 修复

- 🚨 输入后**立即关闭窗口或标签页不再静默丢失未保存内容**（原 300ms 延迟标记脏状态在快速关闭路径上绕过确认）。
- 🗑️ 修复资源管理器删除/移动/复制命令与后端载荷不匹配导致命令失效的问题；批量载荷含无效项时整批拒绝，`Shift+Delete` 永久删除真实生效。
- 🔐 修复"在文件管理器中显示 / 在终端打开"可被构造路径打开到项目外目录的问题（统一项目根边界校验）。
- 🔎 修复预览模式查找跳转不滚动的回归；修复快速大纲在分屏模式跳转后光标漂移。
- 🧯 修复设置保存可被未来版本配置覆盖损坏的问题（版本高于当前支持时拒绝落盘）。
- 🈯 修复 Vim 进入提示显示英文键名而非中文文案。
