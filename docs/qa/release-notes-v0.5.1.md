# 🎉 GlanceMD Ultra v0.5.1 — 代理设置体验重构与网络异步探测优化

> 本版本针对设置页网络代理功能进行体验重构与稳定性修复，优化提示文字排版，并修复测试连接事件分发与后台异步执行，确保界面响应丝滑。  
> 🔍 上个版本：[v0.5.0](https://github.com/VastNext/GlanceMD-Ultra/releases/tag/v0.5.0)

---

## ✨ 改进与优化

### 🌐 代理设置排版重构与体验升级 (`FEAT-003`)
- 📐 **合理控件排版**：将代理模式禁用提示（“将代理模式设为‘使用下方指定代理’后可用”）精准放置在**输入框与测试按钮正下方**，消除此前左侧说明文字过多、右侧空旷的视觉失衡。
- 🎨 **视觉比例均衡**：为代理输入区域限定自适应宽度并采用纵向紧凑布局，左侧标签说明恢复清爽简洁，右侧输入框、测试按钮与状态提示层次分明。

### ⚡ 测试连接异步分发与主线程防卡死
- 🚀 **后台异步网络探测**：将网络代理探测操作移至后台独立线程执行，彻底解除同步网络 I/O 对主线程事件循环的占用，避免代理超时或网络波动时 UI 卡死。
- 📡 **事件分发链路修复**：统一规范网络测试结果事件为 `workspace:proxy-test-result`，并在底层事件网桥中增强前缀分发兼容性，解决此前点击“测试连接”后一直卡在“测试中...”的问题。
