# 🎉 GlanceMD Ultra v0.5.0 — 全局自动换行持久化与双格胶囊视图模式切换

> 本版本针对日常 Markdown 编写与阅读体验进行重大交互升级：引入全局自动换行偏好及持久化联动，并将顶部「编辑/预览」按钮彻底重构为零歧义的微型双格胶囊开关。同时整理防范了开发验证中的后台服务卡死规范。  
> 🔍 上个版本：[v0.4.0](https://github.com/VastNext/GlanceMD-Ultra/releases/tag/v0.4.0)

---

## ✨ 新功能与核心体验升级

### 🔀 全局自动换行持久化与 UI 状态联动 (`Alt+Shift+Y`)
- 💾 **跨标签页与全局记忆持久化**：
  - 过去通过快捷键 `Alt+Shift+Y` 切换换行仅影响当前 DOM 且不落盘，切 Tab 或重载设置会被覆盖。
  - 现在换行切换直接打通全局有效配置（`SettingsApply.patch`）并自动落盘保存至 `settings.json`（`editor.wordWrap`）。
  - **当前所有打开的 Tab、切换 Tab，以及后续新建/打开的所有文件，全部全局同步生效**，重启软件亦能准确记忆。
- 🔘 **顶部工具栏新增自动换行状态按钮 (`#btn-word-wrap`)**：
  - 工具栏操作区新增标准的折行弯折箭头图标（`wrap-text`）；
  - **开启换行时**：按钮点亮 GlanceMD Ultra 标志性的紫粉高亮背景（`var(--heading-glow)`），`aria-pressed="true"`，悬浮提示 `自动换行：已开启 (Alt+Shift+Y)`；
  - **关闭换行时**：按钮呈现常规暗色线框，悬浮提示 `自动换行：已关闭 (Alt+Shift+Y)`；
  - 支持鼠标直接点击按钮在开/关之间快速切换。
- 💬 **即时状态气泡反馈 (Toast)**：
  - 无论是通过快捷键 `Alt+Shift+Y` 还是点击顶部按钮，底部均会弹出 1.2 秒的轻量状态 Toast（`自动换行已开启` / `自动换行已关闭`），带来清晰直观的操作反馈。

### 💊 编辑/预览重构为「微型双格胶囊开关」（Segmented Pill Control）
- 🎯 **彻底终结视觉心智混乱**：
  - 旧版本在预览模式下按钮高亮显示“铅笔”图标，极易给用户带来“我正处于编辑模式”的认知冲突（经典 Action Icon vs Active State 冲突）。
  - 本版本正式将单按钮重构为紧凑精致的双格胶囊控件：`[ ✏️ (编辑) | 👁️ (预览) ]`。
- 💡 **直观的状态呈现逻辑**：
  - **处于编辑模式时**：左格 `✏️` 亮起紫粉高亮背景，右格 `👁️` 保持暗色；
  - **处于预览模式时**：右格 `👁️` 亮起紫粉高亮背景，左格 `✏️` 保持暗色；
  - **分屏模式 (`Ctrl+\`) 下**：两格同时点亮，清晰表明“边写边看”；
  - 点击左格切编辑，点击右格切预览；按 `Ctrl+Shift+V` 快捷键切换时，高亮在两格之间无缝同步；
  - 保留原有 `btn-toggle` 节点作为透明兼容代理，不破坏已有快捷键映射与外部脚本依赖。

## 🔧 工程与开发规范

- 🛡️ **Node.js 临时进程与后台服务防范规范 (`AGENTS.md`)**：
  - 深度排查并总结了在 Windows Git Bash 环境下裸加 `&` 后台运行长服务导致终端 stdio 句柄竞争挂死的事故机理；
  - 固化了“测试优先静态生成”、“严禁裸后台启动”、“显式处理 `EADDRINUSE` 端口冲突”与精准按 PID 杀进程等四项开发避坑铁律。
- 🧪 **测试用例扩充**：
  - 新增 `toolbar-controls.test.js`，补全双格胶囊 UI 模式联动、全局设置 patch 广播与 Toast 触发的全链路测试；前端自动化测试总数增至 467 项全部满分通过。
