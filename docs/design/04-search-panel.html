设计说明
面板位置：与项目树共用左列位（打开搜索时替换树面板，Esc / × 返回树）；不做全项目替换（主计划明确非目标）。
开关样式：Aa / ab / .* 三个等宽 pill，激活态 = --heading-glow 淡渐变底 + 紫字 + --heading-soft 描边，与标题栏 active 按钮同语言。
结果树：按文件分组（文件头 = 图标 + 相对路径 + 计数徽标），命中行 = 行号（等宽右对齐）+ 行文本；当前选中命中行 = --tree-active-bg 紫底。<mark> 用 --mk-mark-bg/--mk-mark-color（暗色琥珀底深字 / 亮色奶黄底深字）。
阈值与上限：跳过二进制与 >5 MB 文件（已跳过 N 个超大文件 入摘要行）；达到结果数上限时摘要行提示"已达上限，可缩小范围"。
键盘：Enter 下一条命中、Shift+Enter 上一条、Esc 关闭面板（回到项目树）。
