- A：G 形视口；

- C：折叠页面 + U。

正式应用图标已采用 `g-viewfinder-baoyu.png`：

- `assets/icon.png` 与设计源文件保持相同字节；
- `assets/icon.ico` 由 `assets/gen_icon.py` 从正式 PNG 生成。
