设计说明与决策点
行状态体系（决策点 1，详见 index）：悬停 = 灰 8%；多选 = 紫 14%（--tree-selected-bg）；激活 = 紫 28% + 2px 渐变左条（--tree-active-bg）+ 高对比文字；定位当前文件 = 1px 紫内描边（不滚动，仅同步高亮）。多选时 reveal 禁用（主计划 §0.2）。
图标：单色线性内联 SVG（决策点 4），folder / doc / link 三形，激活件图标着紫；不按扩展名着色。
右键菜单：阶段 3 落地行为，本稿仅定样式——bg-overlay + 8px 圆角 + menu-shadow，kbd 提示右对齐；删除项红色，永久删除始终展示于其下（执行时二次确认）。
与 split 预览共存：预览开启时编辑器区内部再分栏，树/Outline 面板不受影响（阶段 1 验收项）。
