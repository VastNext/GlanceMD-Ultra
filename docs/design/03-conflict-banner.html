行为矩阵对照（主计划阶段 2 冲突矩阵的 UI 呈现）
tab 状态 × 外部事件UI 呈现
clean × 外部修改自动重载（保留光标 / 滚动）+ 状态栏短暂提示，无横幅
dirty × 外部修改琥珀横幅：重新加载 / 保留编辑版本 / 另存为；"保留编辑版本"后再保存需二次确认覆盖
clean / dirty × 外部删除红色横幅：另存为 / 关闭；内容保留在内存，不静默丢失
× 外部移动可唯一识别 → 静默更新路径（tab 标题 / 树同步）；否则按删除 + 新增处理
自身保存无任何 UI（回环抑制）；监听错误以状态栏提示（watcher-error）
设计说明与决策点
配色语义（决策点 2，index）：外部修改 = 琥珀 --warning / --warning-soft + 左缘 3px 色条；外部删除 = --danger-soft 底 + --danger 标题与左条。备选方案为统一中性 bg-raised 卡（同既有导航回退卡样式）。
按钮层级：横幅按钮全中性描边（bg-overlay + border，hover 紫描边，沿 navigation-fallback 惯例），不在警示语境里用渐变主按钮强化任何单项动作。
文案要素：标题（结论）+ 副行（等宽字体文件路径 · 磁盘修改时间 · 后果提示）。时间格式随系统区域。
叠加规则：多个 tab 同时冲突时横幅逐个展示当前激活 tab 的冲突，状态栏显示未处理计数；× 仅暂时关闭，事件源再次变更时重现。
