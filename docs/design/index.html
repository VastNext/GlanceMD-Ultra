待维护者确认的设计决策点
决策点 1

多选 / 激活高亮色

本稿方案：激活行 = --tree-active-bg（紫 28%）+ 2px 渐变左条 + --tab-active-text 文字；多选行 = --tree-selected-bg（紫 14%）文字不变；悬停 = 灰 8%。备选：多选改用灰底、激活才用紫。多选时 reveal 禁用（主计划 §0.2 已固化）。

决策点 2

冲突横幅配色

本稿方案：外部修改 = 琥珀警示（--warning / --warning-soft），外部删除 = 危险红淡底（--danger-soft + --danger 文字），语义分级。备选：统一中性 bg-raised + 左缘色条（同既有导航回退卡样式）。横幅均为非模态、下推内容区。

决策点 3

主按钮是否渐变填充

本稿方案：欢迎页"打开项目"用 --heading-gradient 填充白字作为唯一主按钮示范；冲突横幅三按钮保持中性描边（避免在警示语境里强化危险动作）。备选：全部按钮中性、渐变只用于指示条与文字。

决策点 4

文件图标着色策略

本稿方案：单色线性图标（folder / doc / link），仅激活件图标着 --mk-heading，克制且省体积。备选：按扩展名着色（VS Code Seti 风格）——与零依赖原则兼容但增加图标资产维护面。
