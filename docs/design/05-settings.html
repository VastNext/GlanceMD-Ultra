设计说明与决策点
分类：对齐方案 §7.1 七类——外观与布局 / 文件类型与排除规则 / 文件监听与自动保存 / 搜索 / 编辑器与大文件模式 / 快捷键 / 恢复与启动行为；激活态 = heading-glow 底 + 2px 紫左条（与树激活态同语言）。
两级设置：全局 + 项目（.glancemd/settings.json）；行内出现 项目已覆盖 徽标（紫）表示该项被项目设置覆盖，点击徽标可定位到 JSON。
快捷键页（快捷键分类内）：命令搜索 + 组合键录制 + 冲突检测（冲突阻止保存，红描边 + 说明）+ 清除 / 恢复默认 / 导入导出；键位显示按平台——Windows / Linux 用 Ctrl / Alt，macOS 用 Cmd / Option。
设置 JSON 入口：标题栏右侧 {} 按钮，全局与项目两个文件分别可达（项目文件不存在时按全局设置控制是否自动创建）。
迁移：主题、布局、窗口状态等既有散落持久化项迁入统一设置体系（阶段 5 交付，含迁移测试）。
