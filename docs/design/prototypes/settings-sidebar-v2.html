# GlanceMD Ultra · 轻量原生工作区

GlanceMD Ultra 专注于为本地 Markdown 与结构化项目提供极速、无运行时负担的原生编辑体验。二进制仅 2–5MB，启动耗时低于 120ms，零 Electron 与 Monaco 依赖。

## 视觉设计体系：Quiet Technical Layers

暗色模式采用 Linear / Raycast 风格的 Surface Ladder 递进，浅色模式采用 Cursor / Notion 的暖白微边框（Hairline）。普通设置行不做厚重卡片，视觉层级完全由表面深度与分割线构筑。

"纯粹的工具性美学：克制、精密、轻盈。"
### 侧栏排版与树形密度联动

通过单一滑动条（12–18px），可全局等比联动字号、图标尺寸、箭头角度、行高（26–38px）、层级缩进与 Outline 标记。
