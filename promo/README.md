## 翻译方向约定

- `zh` 系列界面：中文文档 → **译成英文**（浮窗目标语言 English）
- `en` 系列界面：英文文档 → **译成中文**（浮窗目标语言 简体中文）
- 6️⃣ 系列：编辑器输入中文 → 划词气泡内切换目标语言为 English → 替换写回
